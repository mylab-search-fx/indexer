# Инструкции

* все тесты делаются с участием реальной БД. MariaDB развёрнута на локальной машине на порту 3306
* работу с БД следует вести через IRedisManager из библиотеки MyLab.Db (документация тут `references/MyLab.Db.md`). В качестве провайдера по умолчанию использовать MyLab.Search.Indexer.Infrastructure.Database.MariaDb10DataProvider. Логин/пароль - test/test.
* реализовать на уровне проекта инициализацию тестовых БД. Делать это через GlobalTestFixture с интерфейсом IAsyncLifetime. При асинхронной инициализации удалять и создавать две базы: для индексатора с его таблицами и базу-источник с данными, которые будут индексироваться. 
* в классе TestTools должен быть метод очистки таблиц всех тестовых баз, которые на сервере находятся не "из коробки". Этот метод следует вызывать при инициализации каждого теста - в асинхронной инициализации реализации интерфейса IAsyncLifetime. Каждый тест должен наполнять базы своими данными.
